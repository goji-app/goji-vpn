# Тестирование

## Автоматические проверки (CI)

| Проверка | Где |
|---|---|
| Полнота локализации ru/en, совпадение подстановок | `Scripts/check-strings.py` |
| Юнит-тесты (16): сборка конфига Xray, разбор geosite.dat, разбор подписки, утилиты | `Tests/CoreLogicTests.swift` |
| Компиляция приложения и расширения для симулятора и устройства (arm64, Release) | `.github/workflows/ios.yml` |
| Интерфейс в демо-режиме (светлая/тёмная тема, ru/en) | снимки экрана в артефакте CI |

Что CI **не** проверяет: реальное VPN-подключение (NetworkExtension не работает в симуляторе и
без подписи). Это проверяется вручную на устройстве — ниже.

## Ручная проверка на iPhone (перед каждой отправкой на ревью)

Сборка из TestFlight на реальном устройстве; лучше два устройства (iOS 16/17 и iOS 18+) и
два типа сети (Wi-Fi и мобильная).

### Первый запуск и вход
- [ ] Экран конфиденциальности показывается до входа; ссылка на политику открывается.
- [ ] Вход по email: код приходит, вводится (в т.ч. автоподстановкой из «Почты»), неверный код
      → понятная ошибка, повторная отправка через 60 с.
- [ ] Новый email создаёт аккаунт; у аккаунта без подписки — карточка «Нет активной подписки»,
      «Активировать пробный период» работает (или показывает ошибку бэкенда).
- [ ] QR-перенос: Аккаунт → Перенести вход на устройстве A → «Войти по QR» на устройстве B →
      подтверждение → вход. Код старше 10 минут отклоняется.
- [ ] Ссылка `godjivpn://transfer?...` из системной камеры открывает приложение с подтверждением.

### Подключение
- [ ] Первое «Включить» → системный запрос «Добавить конфигурацию VPN» → разрешить → статус
      «Вы в <стране>», таймер идёт, глобус показывает маршрут, значок VPN в статус-баре.
- [ ] Отказ в запросе VPN → понятная ошибка, повторная попытка снова спрашивает.
- [ ] Скорость растёт при загрузке (например, видео), график обновляется.
- [ ] Сайты открываются; российские сервисы (ya.ru, gosuslugi.ru, банки) — тоже (идут напрямую).
- [ ] `ipwho.is` в Safari показывает IP сервера, а не провайдера.
- [ ] Смена сервера при включённом VPN — без отключения (значок VPN не пропадает), страна
      меняется, баннер о реальной стране — если IP не соответствует названию.
- [ ] «Отключить» → статус «Пока без защиты».
- [ ] Автовыбор LTE/EU подключается.
- [ ] Повторное открытие приложения при включённом VPN — правильный статус и время.
- [ ] VPN держится 30+ минут с выключенным экраном; после разблокировки сайты открываются.
- [ ] Переход Wi-Fi ↔ мобильная при включённом VPN — связь восстанавливается сама (сторож).

### Kill switch и автоподключение
- [ ] Kill switch вкл. → подключиться → в «Журналы → Туннель» нет ошибок, сайты открываются.
      Проверка блокировки: при включённом VPN заблокировать узел (например, выбрать заведомо
      недоступный сервер) — пока туннель переподключается, сайты НЕ должны открываться мимо VPN.
      После ручного «Отключить» интернет работает напрямую — это ожидаемо.
- [ ] Автоподключение «В чужих Wi-Fi»: подключение к Wi-Fi поднимает VPN без открытия
      приложения; доверенная сеть — VPN отключается.
- [ ] «Всегда»: после перезагрузки iPhone VPN поднимается сам.
- [ ] Ручное отключение при автоподключении — VPN не поднимается сам до следующего включения.

### Сайты мимо VPN
- [ ] Добавить `2ip.ru` → на 2ip.ru виден настоящий IP, на ipwho.is — IP сервера.
- [ ] Удалить домен → снова IP сервера (ядро перезапускается без разрыва).

### Аккаунт, поддержка, прочее
- [ ] Тариф, срок, дни, лимит устройств; текущее устройство помечено «Это».
- [ ] Переименование устройства; удаление (на платном тарифе) / сообщение «через поддержку»
      (пробный).
- [ ] Реферальная ссылка копируется и отправляется через «Поделиться».
- [ ] Новости отображаются, ссылки на оплату в кнопках не показываются.
- [ ] Поддержка: новое обращение (с темой/очередью), ответ, вложения (фото, PDF, журналы),
      статусы, закрытые обращения; FAQ.
- [ ] Проверка IP и DNS: при включённом VPN — «Утечек не найдено», при выключенном — «VPN
      выключен».
- [ ] Журналы: записи есть, «Поделиться» отдаёт файл, токенов в тексте нет.
- [ ] Тема светлая/тёмная/системная; крупный шрифт (Настройки iOS → Экран → Размер текста) не
      ломает экраны; VoiceOver читает кнопки.
- [ ] Siri / Быстрые команды: «Включи Goji VPN» / «Выключи Goji VPN».
- [ ] Уведомления: разрешение запрашивается после входа; напоминание об окончании подписки
      запланировано (можно проверить на тестовом аккаунте с коротким сроком).
- [ ] Выход из аккаунта: VPN отключается, профиль VPN удаляется из Настроек iOS.
- [ ] Удаление аккаунта (на тестовом аккаунте!): обращение создаётся, выход выполнен.

### Нагрузка и память
- [ ] Xcode → Debug → Attach to Process → PacketTunnel: память расширения при активном
      использовании < 40 МБ (лимит ~50 МБ). Особенно — на узлах-балансировщиках и после
      нескольких смен сервера.
- [ ] Батарея: Настройки iOS → Аккумулятор — расход Goji VPN адекватен за сутки.
