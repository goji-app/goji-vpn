# Goji VPN — Android

Клиент VPN-сервиса на Kotlin + Jetpack Compose + Hilt, с реальным туннелем на Xray-core
(через [libXray](https://github.com/XTLS/libXray)) и hev-socks5-tunnel. Работает с
бэкендом на [Remnawave](https://remna.st/).

## Возможности

**Подключение**
- VPN-туннель (VLESS + Reality) через `GodjiVpnService` — foreground-сервис с живым
  статус-уведомлением (страна, скорость, кнопка отключения). Реализация подъёма туннеля
  (`establishTunnel()`) в этом репозитории не публикуется — в коде оставлена только форма
  класса, необходимая для сборки остального приложения
- 3D-глобус (OpenGL ES) с подсветкой страны подключения, дугой и живой анимацией — светлая
  и тёмная палитра
- Автопереключение сети: при глушении мобильной связи — на резервный российский узел,
  на Wi-Fi — обратно на обычный, полностью автоматически
- Домашний виджет: изменяемый размер от 2×1 до 3×3, при увеличении показывает список
  серверов подписки с выбором узла прямо на рабочем столе; кнопка подключения работает
  без открытия приложения, цвета следуют системной теме телефона

**Вход и подписка**
- Email + одноразовый код, а также нативный OAuth (Google, Яндекс) через PKCE и Custom Tabs
- Список серверов из реальной подписки с проверкой пинга (через прокси GET/HEAD, TCP или
  ICMP — настраивается)
- Экран тарифов с реальными ценами/сроком/лимитом трафика, локальные уведомления о скором
  окончании подписки и об успешной оплате

**Настройки**
- Тёмная/светлая тема
- Языки интерфейса: русский, английский, китайский — переключаются мгновенно, без перезапуска
- Настраиваемый способ и URL проверки пинга серверов
- Журнал приложения: 5 отдельных категорий (основной, ядро, подписки, служба, пуши) и
  5 уровней детализации — хранится только на устройстве, никогда никуда не отправляется
  автоматически
- «О программе»: версия приложения, версия XRay-ядра, HWID, информация об устройстве

**Безопасность**
- Локальный кеш подписки и список серверов зашифрованы (`androidx.security.crypto`)
- Устройство привязывается к подписке через заголовок `X-HWID`

## Стек

Kotlin · Jetpack Compose (Material 3) · Hilt · Retrofit + Moshi · OkHttp · DataStore
Preferences · WorkManager · androidx.security-crypto · Xray-core (libXray.aar) ·
hev-socks5-tunnel

## Сборка

Открывается в Android Studio (последняя стабильная версия). Перед первым запуском положите
рядом с проектом:

- `app/libs/libXray.aar` — соберите по инструкции [XTLS/libXray](https://github.com/XTLS/libXray)
  (`python build/main.py android`)
- `app/keystore.properties` + сам keystore-файл — нужны только для подписанной релизной
  сборки (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`); без них соберётся debug
  и неподписанный release

> **Windows:** Android Gradle Plugin не собирает проект из папки с кириллицей в пути.
> Если ваш чекаут лежит в такой папке — соберите копию `app/` в ASCII-путь
> (например `C:\build\godji`) и запускайте `gradlew` уже оттуда.

```bash
./gradlew assembleDebug     # debug-сборка, подпись не нужна
./gradlew assembleRelease   # релиз, нужен app/keystore.properties
```

Собирается и публикуется одна universal-сборка (`Goji.apk`) со всеми поддерживаемыми
архитектурами (arm64-v8a, armeabi-v7a) внутри — отдельных сборок под конкретный процессор
нет. Готовые APK за все версии — во вкладке [Releases](../../releases) этого репозитория.

## Структура

```
app/src/main/java/xyz/gojihub/vpn/
├─ auth/          # Email-OTP, PKCE, TokenManager, OAuthCallbackActivity
├─ di/            # Hilt-модули (Retrofit/OkHttp)
├─ geo/           # Определение страны/города узла по remark, приветствия на языке страны
├─ globe/         # OpenGL-рендерер 3D-глобуса
├─ i18n/          # Каталог строк интерфейса (RU/EN/ZH) и переключатель языка
├─ network/       # Retrofit-интерфейс и модели Remnawave API
├─ settings/      # DataStore-настройки (тема, язык, пинг, уровень логов и т.д.)
├─ subscription/  # Подписка, список серверов, пинг, локальные уведомления
├─ util/          # AppLogger (категории/уровни), форматирование дат и т.п.
├─ vpn/           # GodjiVpnService — форма класса, реальная реализация туннеля закрыта
├─ widget/        # Виджет на главный экран
└─ ui/
   ├─ connect/    # Главный экран (глобус, статус, трафик)
   ├─ servers/    # Список серверов
   ├─ plans/      # Тарифы и подписка
   ├─ settings/   # Настройки, журналы, уровень логирования, пинг
   ├─ login/      # Вход и подтверждение email
   ├─ theme/      # Цвета и типографика (светлая/тёмная тема)
   └─ globe/      # Compose-обёртка над OpenGL-глобусом
```
