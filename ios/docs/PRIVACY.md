# Конфиденциальность: App Privacy и политика

## Что реально собирает iOS-приложение

Сверено с кодом (`APIClient`, `SubscriptionStore.fetchNodes`, `AuthService`, `SupportViews`,
`AppLog`). Сторонних SDK (аналитика, реклама, крэш-репорты) **нет**.

| Данные | Когда | Куда | Зачем |
|---|---|---|---|
| Email | вход | gojihub.xyz | аккаунт, вход по коду |
| ID устройства (HWID — случайный UUID приложения, не рекламный ID) | загрузка списка серверов | subs.gojihub.xyz (заголовок `X-HWID`) | лимит устройств подписки |
| Модель iPhone, версия iOS, версия приложения | то же | subs.gojihub.xyz | список устройств в аккаунте |
| Сообщения в поддержку, вложения (фото/видео/PDF), журналы приложения — по выбору пользователя | отправка обращения | gojihub.xyz | поддержка |
| Название устройства (если пользователь переименует) | «Аккаунт → Устройства» | gojihub.xyz | список устройств |
| Сетевой трафик | при включённом VPN | VPN-серверы | работа VPN; **не журналируется** (подтвердить у команды серверов!) |
| IP-адрес | любой запрос | серверы | неизбежно технически; не используется для идентификации (подтвердить) |

Проверка утечек обращается к сторонним сервисам `ipwho.is`, `ipapi.co`, `edns.ip-api.com` —
они видят IP устройства в момент проверки (только по нажатию кнопки). Пинг — к
`cp.cloudflare.com` через VPN-серверы. Геоданные скачиваются с `raw.githubusercontent.com`.
Это нужно упомянуть в политике как «сторонние сервисы, к которым приложение обращается».

## Ответы анкеты App Privacy (App Store Connect → App Privacy)

**Do you or your third-party partners collect data from this app?** → **Yes**.

| Тип данных (Apple) | Собирается | Связан с пользователем | Трекинг | Цель |
|---|---|---|---|---|
| Contact Info → **Email Address** | Да | Да | Нет | App Functionality |
| Identifiers → **Device ID** | Да | Да | Нет | App Functionality |
| User Content → **Customer Support** | Да | Да | Нет | App Functionality |
| User Content → **Photos or Videos** | Да (вложения в поддержку) | Да | Нет | App Functionality |
| Diagnostics → **Other Diagnostic Data** | Да (журналы, модель/версия iOS) | Да | Нет | App Functionality |
| Usage Data, Location, Browsing History, Search History, Purchases, Financial Info, Health, Contacts, Sensitive Info | **Нет** | — | — | — |

- **Browsing History — НЕ отмечать**: приложение не собирает историю, а VPN-сервер её не
  журналирует. Если на серверах журналы есть — это нужно отразить (и пересмотреть заявления
  «без журналов» в приложении и описании).
- Для каждого типа на вопрос «Is this data used to track you?» → **No**.
- Итог в карточке: «Data Linked to You: Contact Info, Identifiers, User Content, Diagnostics»;
  «Data Not Used to Track You».

Манифесты в сборке согласованы с этими ответами: `App/Resources/PrivacyInfo.xcprivacy`
(EmailAddress, DeviceID, CustomerSupport, PhotosorVideos, OtherDiagnosticData; трекинга нет).

## Политика конфиденциальности — что добавить для iOS

Текущая политика (Telegraph, 2026-09-20) писалась под Android. Для App Store её нужно
дополнить. Ниже — готовый раздел; юрист должен проверить соответствие 152-ФЗ/GDPR и реальной
практике хранения на серверах. Опубликовать можно на Telegraph тем же токеном (см. память
проекта `reference_telegraph_legal_docs`) или на сайте gojihub.xyz; новую ссылку — в
`AppConstants.privacyPolicyURL` и в App Store Connect.

```
Приложение Goji VPN для iOS

Какие данные обрабатывает приложение:
1. Адрес электронной почты — для входа в аккаунт по одноразовому коду и восстановления доступа.
2. Идентификатор устройства — случайное значение, которое приложение создаёт при первом запуске
   и хранит в защищённом хранилище iOS (Keychain). Он не является рекламным идентификатором и
   не позволяет отслеживать вас в других приложениях. Используется только для соблюдения лимита
   устройств вашей подписки.
3. Модель устройства, версия iOS и версия приложения — для отображения списка ваших устройств
   в аккаунте.
4. Обращения в поддержку и файлы, которые вы прикладываете к ним (в том числе технический журнал
   приложения) — только если вы сами их отправляете.

Чего мы не делаем:
— не ведём журналы посещаемых сайтов, DNS-запросов и содержимого трафика;
— не используем рекламу, сторонние трекеры и сервисы аналитики;
— не продаём и не передаём ваши данные третьим лицам, кроме случаев, прямо предусмотренных
  законом.

Разрешения: камера используется только для сканирования QR-кода входа; изображение
обрабатывается на устройстве и никуда не передаётся. Геолокация не запрашивается.

Сторонние сервисы: по нажатию «Проверка IP и DNS» приложение обращается к ipwho.is, ipapi.co и
edns.ip-api.com, которые видят ваш IP-адрес в момент проверки. Для обновления правил
маршрутизации приложение загружает открытые списки с raw.githubusercontent.com.

Хранение и удаление: данные аккаунта хранятся, пока существует аккаунт. Удалить аккаунт можно
в приложении: «Настройки → Аккаунт → Удалить аккаунт». Удаление выполняется в течение 7 дней,
подтверждение приходит на email. Журналы приложения хранятся только на вашем устройстве и
удаляются вместе с приложением или кнопкой «Очистить».

Контакты: <email поддержки>, <юридическое название и адрес организации-разработчика>.
```

## Что сделать команде

- [ ] Подтвердить, что VPN-узлы и бэкенд **не журналируют** посещённые ресурсы/DNS/трафик
      (иначе убрать эти обещания из приложения, описания и политики).
- [ ] Обновить и опубликовать политику; заменить ссылку в `AppConstants` и App Store Connect.
- [ ] Указать в политике организацию-разработчика (как в Apple Developer Program).
- [ ] Обеспечить срок удаления аккаунта ≤ 7 дней с подтверждением на email.
