# Публикация в Google Play

Что уже сделано в коде (флейвор `play`) и что заполнить в Play Console.

Сборка: `./gradlew bundlePlayRelease` → `app/build/outputs/bundle/playRelease/app-play-release.aab`.
Подпись — через Play App Signing (загружаем ключом загрузки).

## Что сделано в приложении

| Требование Google | Где |
|---|---|
| Нет самообновления в обход Play, нет `REQUEST_INSTALL_PACKAGES` | `ENABLE_SELF_UPDATE=false`, `src/play/AndroidManifest.xml` |
| Нет оплаты и ссылок на оплату вне Google Play | `ENABLE_EXTERNAL_CHECKOUT=false`: скрыты «Продлить», тарифы с ценами, скидка, кабинет партнёра, баннер бота |
| Нет входа через встроенный браузер на весь сайт | `ENABLE_WEB_LOGIN=false`: только email-код и QR-перенос |
| Удаление аккаунта внутри приложения | Настройки → «Удалить аккаунт» (заявка тикетом в поддержку + выход) |
| Описание foreground service `specialUse` | `PROPERTY_SPECIAL_USE_FGS_SUBTYPE` у `GodjiVpnService` |
| Регистрация и пробный период без бота | Главная → «Активировать» (`POST /api/dashboard/trial`, только бесплатный триал) |
| Пояснение перед запросом геолокации | Правила сети → «Разрешить» → диалог, потом системный запрос |
| targetSdk ≥ 36, нативные библиотеки под страницы 16 КБ | targetSdk 37, `libgojni.so`/`libhev-socks5-tunnel.so` выровнены по 16384 |

## Что заполнить в Play Console

### Аккаунт разработчика
- Тип **Организация** с номером D-U-N-S — VPN-приложения от личных аккаунтов не принимаются.

### Удаление аккаунта (Data deletion)
- Веб-страница: https://telegra.ph/Udalenie-akkaunta-Goji-VPN-10-11 (без приложения — обращение в поддержку на gojihub.xyz).
- В приложении путь: Настройки → «Удалить аккаунт».
- Заявки приходят тикетом «Удаление аккаунта» — аккаунт удаляется после обработки заявки поддержкой (так сказано пользователю).

### Foreground service (App content → Foreground service permissions)
- Тип: **Special use**.
- Описание: «Служба держит VPN-туннель (VpnService) активным, пока пользователь подключён к Goji VPN. Запускается только по нажатию пользователя «Подключить» и показывает постоянное уведомление».
- Если система остановит службу: VPN-соединение оборвётся, трафик пойдёт без защиты.
- Видео: включение VPN кнопкой → уведомление в шторке → отключение.

### VPN (политика VpnService)
- В описании магазина прямо указать, что приложение — VPN и создаёт защищённый туннель.
- Трафик шифруется (VLESS/Reality/TLS через Xray), рекламу не подменяет, трафик не продаёт.

### Безопасность данных (Data safety)
- Собирается: email (аккаунт), идентификатор устройства (HWID — лимит устройств подписки), модель устройства и версия Android, обращения в поддержку.
- Не собирается: история посещений, содержимое трафика, геолокация (имя Wi-Fi сети хранится только на телефоне).
- Данные шифруются при передаче; пользователь может запросить удаление.
- Политика конфиденциальности: https://telegra.ph/Politika-konfidencialnosti-Goji-VPN-09-20
  (дополнить пунктами про HWID/модель устройства и про удаление аккаунта).

### Доступ к приложению (App access)
- Демо-аккаунт для проверяющих: вход без email-кода (постоянный код или пароль),
  активная подписка, лимит устройств с запасом (проверяющие ставят на несколько устройств).

### Прочее
- Возрастной рейтинг (анкета), целевая аудитория 18+, реклама — нет.
- Новости (`/api/broadcasts`) показываются в приложении как есть: в них не должно быть
  ссылок на оплату на сайте — иначе это нарушение правил о платежах в Play-сборке.
